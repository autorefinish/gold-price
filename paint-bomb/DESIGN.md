# 페인트 밤 러시 (Paint Bomb Rush) — 기획서

## 1. 레퍼런스 분석 (스크린샷 속 광고 게임)

스크린샷의 게임은 **"러너 + 슈터 + 게이트 선택"** 장르(일명 하이퍼캐주얼 러너 슈팅)입니다.

| 요소 | 레퍼런스에서 보이는 것 | 핵심 재미 |
|---|---|---|
| 시점 | 세로 화면, 뒤에서 내려다보는 3인칭, 다리/도로 위 일직선 진행 | 한 손 조작, 화면이 단순 |
| 조작 | 좌우 이동만, 사격은 **자동** | 진입장벽 0 |
| 적 | 좀비 떼가 앞에서 몰려옴, 끝에 거대 보스(체력 수치 표시) | 압박감 → 해소의 쾌감 |
| 게이트 | `+2`, `×4`, `-8` 같은 숫자 게이트 중 하나를 골라 통과 | 순간 판단 / 성장 |
| 성장 | 게이트·상자로 무기 강화, 인원/화력 증가 | "강해지는 느낌" |
| 수익 구조 | 광고는 러너, 본편은 4X 전략 (광고-본편 괴리) | — |

**가져올 것:** 세로 도로, 좌우 드래그 + 자동 사격, 몰려오는 적, 선택 게이트, 스테이지 끝 보스.
**바꿀 것:** "체력 깎기" 대신 **"색을 맞춰야 죽는"** 퍼즐 규칙 → 단순 반사신경 게임이 아니라 **판단**이 필요한 게임.

## 2. 핵심 규칙 — 색 섞기

- 스테이지 시작 시 **목표 색**이 정해짐 (예: 주황).
- 적은 각자 색을 가지고 옴 (흰색, 빨강, 노랑, 파랑 …).
- 페인트 폭탄에 맞으면 적의 색에 **폭탄 색이 섞임**.
- 적의 색이 **목표 색과 같아지는 순간 사망**.

섞기 표 (물감 혼합, 3원색 기준):

| 적 색 \ 폭탄 | 빨강 | 노랑 | 파랑 |
|---|---|---|---|
| 흰색 | 빨강 | 노랑 | 파랑 |
| 빨강 | 빨강 | **주황** | **보라** |
| 노랑 | **주황** | 노랑 | **초록** |
| 파랑 | **보라** | **초록** | 파랑 |
| 2차색 + 나머지 원색 | → **갈색(진흙)** | | |

- 목표 색에 없는 성분이 섞이면 **오염** 상태 → 그 색으로는 절대 목표에 도달 불가.
- **신너(🧴)** 폭탄: 적을 흰색으로 되돌림. 개수 제한 → 오염된 적 처리용 자원.
- 폭탄은 **폭발 범위(스플래시)** 가 있어서 주변 적에게도 색이 묻음 → 잘못 쏘면 떼로 오염되는 리스크 / 잘 쏘면 연쇄 처치.

(구현: 색 = 3비트 마스크 R=1, Y=2, B=4. 섞기 = OR, 사망 = `mask === target`, 오염 = `mask & ~target`)

## 3. 무기 (모든 무기는 현재 선택한 색의 페인트를 발사)

| 무기 | 특징 |
|---|---|
| 페인트 건 | 기본, 중간 연사 |
| 샷건 | 3갈래 확산, 근거리 다수 |
| 개틀링 | 아주 빠른 연사, 스플래시 없음 → 정밀 |
| 바주카 | 느리지만 큰 폭발 범위 → 무리 한 번에 칠하기 (오염 위험도 큼) |

## 3-1. 적 종류
| 적 | 등장 | 특징 |
|---|---|---|
| 슬라임 | 1~ | 기본. 3마리 무리로도 등장 |
| 페인트 박쥐 | 1~ | 좌우 지그재그 비행 |
| 러너 | 2~ | 빠름 |
| 방패병 | 2~ | 방패가 3번까지 페인트를 막음 → 깨야 칠해짐 |
| 분열체 | 3~ | 처치 시 흰색 꼬마 2마리로 분열 |
| 골렘 | 3~ | 목표 색을 두 번 만들어야 쓰러짐, 닿으면 하트 2개 |
| 카멜레온 | 4~ | 2~3초마다 색이 저절로 바뀜(바뀌기 직전 깜빡임) |
| 킹 슬라임(보스) | 각 스테이지 끝 | 목표 색이 될 때마다 체력 1칸, 부하 소환 |

## 4. 게이트 (도로 위, 둘 중 하나 통과)
`+1 탄` / `연사 +25%` / `폭발범위 +` / `신너 +5` / 무기 교체 / 나쁜 게이트(`-1 탄`, `연사 -`).

## 5. 스테이지 구성
| 스테이지 | 목표 색 | 등장 적 | 포인트 |
|---|---|---|---|
| 1 | 주황 (빨+노) | 흰/빨/노 | 기본 학습 |
| 2 | 초록 (노+파) | 흰/노/파 + **빨강(오염)** | 신너 사용 학습 |
| 3 | 보라 (빨+파) | 모든 원색 + 2차색 | 혼합 판단 |
| 4 | 갈색 (3색 전부) | 전부 | 모든 적이 해답 있음, 대신 3번 칠해야 함 |
| 5+ | 랜덤 | 빨라짐 | 무한 모드 |

스테이지 끝에는 **보스**: 목표 색이 될 때마다 체력 1칸 감소 후 색이 무작위로 바뀜.

## 6. 조작
- 모바일: 화면 아무데나 드래그 → 좌우 이동, 하단 색 버튼으로 페인트 교체.
- PC: ←/→ 또는 A/D 이동, 1·2·3 색, 4 신너.
